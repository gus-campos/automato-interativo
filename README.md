# Automato Interativo

Programa que renderiza uma ilustração interativa de um atômato.

Stack:

- React
- TypeScript
- Mantine

## Como rodar localmente

Para executar esse projeto é necessário ter o Node instalado no ambiente. Instruções de instalação do node [aqui](https://nodejs.org/pt/download).

Execute os seguintes comandos:

```bash
git clone https://github.com/gus-campos/automato-interativo
cd automato-interativo
npm install
npm run dev
```
